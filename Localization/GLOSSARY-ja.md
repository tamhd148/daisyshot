# Daisyshot — Japanese glossary

Use these terms everywhere so the UI reads as one voice. Follow Apple's Japanese macOS style:
です/ます for sentences, nouns or verb-stem phrases for labels and menu items (「〜を表示」「〜を開く」), full-width
punctuation in sentences (「」、。？：（）), no trailing 。 on short labels and toggles, half-width digits and Latin
letters with no space next to kana/kanji (「5秒」「Finderに表示」「GIFを収録」). Quoted UI names (settings panes, buttons)
go in 「」 and paths use 「システム設定」›「プライバシーとセキュリティ」. Use Apple's katakana spellings: ウインドウ,
フォルダ, エディタ, ポインタ, グレイ, サムネール, ジェスチャ.
Keep in English: Daisyshot, GIF, PNG, JPG/JPEG, HEIC, TIFF, WebP, MP4, OCR, URL, API, Retina, Studio (「Studioモード」),
Spotlight, Finder, Dock, macOS, key names and glyphs (⌘, ⌥, ⇧, Esc, Space, Return, Option, Command, Shift),
file-name templates and tokens (%Y, %H…), /regex/, ratio labels (16:9, 1 : 1).
