# Daisyshot — Korean glossary

Use these terms everywhere so the UI reads as one voice. Terminology follows Korean macOS (Apple's own wording for
menus, System Settings panes and standard actions).

Tone:
- Labels, menu items, buttons, toggles: nouns or noun phrases ending in a noun/-기 form ("영역 캡처", "데스크탑 아이콘 가리기"), no trailing period.
- Descriptions and statements: formal polite -습니다/-ㅂ니다 ("…에 적용됩니다.").
- Instructions to the user: -십시오 ("…을 켜십시오."), as in Korean macOS alerts. Numbered steps: plain -ㅂ니다 ("…을 엽니다.").
- Questions in alerts: -겠습니까? ("…닫겠습니까?").
- Toasts / status: short noun + 됨 / 없음 / 실패 ("클립보드에 복사됨", "저장할 수 없음: %@").
- Particles after a %@ placeholder use the neutral form: 을(를), 이(가), 와(과), (으)로. After "Daisyshot" use 이/을/은/으로 (final ㅅ).
- Shortcut hints keep the English spacing: "복사 (⌘C)"; hold-key hints use "⌥: …".

Keep in English: Daisyshot, GIF, PNG, JPG/JPEG, HEIC, TIFF, WebP, HEVC, OCR, URL, API, Retina, Studio (mode name),
Spotlight / Finder / Dock / Space (macOS feature names), key names (⌘, ⌥, ⇧, Esc, Space, Return, Command, Option, Shift),
file-name templates and tokens, /regex/, ratio and size labels ("16:9", "1080 × 1920").

System Settings names as Korean macOS shows them: 시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 녹음 /
손쉬운 사용; 시스템 설정 › 일반 › 로그인 항목; 시스템 설정 › 키보드 › 키보드 단축키… › 스크린샷.
