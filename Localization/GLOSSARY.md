# Daisyshot — Vietnamese glossary

Use these terms everywhere so the UI reads as one voice. Tone: short, friendly, natural Vietnamese as in macOS
(Vietnamese system UI), sentence case, no trailing period on labels, "bạn" when addressing the user.
Keep in English: Daisyshot, GIF, PNG, JPG, OCR, URL, API, Retina, Studio, Spotlight (macOS feature), Finder,
macOS names of system settings panes when quoting them (System Settings › Privacy & Security → "Cài đặt hệ thống ›
Quyền riêng tư & Bảo mật", the names macOS uses in Vietnamese), key names (⌘, ⌥, Esc, Space → "Phím cách" only in prose).
