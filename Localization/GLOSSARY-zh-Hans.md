# Daisyshot — Simplified Chinese (zh-Hans) glossary

Use these terms everywhere so the UI reads as one voice. Tone: concise, neutral, as in Simplified Chinese macOS; address the
user as “你”. Follow Apple's zh-Hans UI style:
- Full-width punctuation in sentences: ，。：；？！（）“” and ——/— for dashes; Chinese quotes “…” replace English "…".
- No trailing 。 on short labels, menu items, buttons and toggles; questions in alerts read “要…吗？”.
- Half-width digits. A space goes around Latin words and product names (Daisyshot、macOS、Mac、App、GIF、PNG、OCR、
  URL、API、Retina、Studio), but not between Chinese and digits or format specifiers (“5秒”、“已拷贝%d个字符”).
- Keep in English: Daisyshot, GIF, PNG, JPEG, HEIC, TIFF, WebP, MP4, HEVC, sRGB, OCR, URL, API, Retina, Studio (mode name),
  regex, file-name tokens, ratio labels (16:9), key names and glyphs (⌘ ⌥ ⇧ ⎋ ⌫ Esc Space Return Command Option Shift).
- macOS names use Apple's Chinese wording: 系统设置 › 隐私与安全性 › 录屏与系统录音 / 辅助功能；系统设置 › 通用 › 登录项；
  系统设置 › 键盘 › 键盘快捷键… › 截屏；访达 (Finder)、聚焦 (Spotlight, the macOS search)、程序坞 (Dock)、废纸篓 (Trash)、
  快速查看 (Quick Look)、空间 (Space).
