# Daisyshot — gói bàn giao thiết kế

| Thư mục / file | Nội dung |
|---|---|
| `DESIGN_SPEC.md` | Đặc tả cho lập trình: màu (sáng/tối), chữ, kích thước, từng màn hình đổi gì, checklist đổi tên |
| `CLAUDE_CODE_PROMPT.md` | Câu lệnh dán vào Claude Code |
| `tokens/DaisyshotTheme.swift` | File màu + kích thước dùng ngay trong SwiftUI |
| `assets/app-icon/handles` | Icon mặc định (02). Có `AppIcon.appiconset` kéo thẳng vào Xcode, PNG 1024, SVG tách lớp nền / hình |
| `assets/app-icon/crosshair`, `viewfinder` | Icon 01 và 03 để chọn trong Settings |
| `assets/menubar` | Icon thanh menu: thường, đang quay (một màu), đang quay nhụy vàng (bản đen + trắng), SVG + PNG @1x/@2x |
| `assets/logo` | Logotype, bản ghép ngang/dọc, dấu hoa |
| `reference/html` | Mã HTML của mọi bảng trên canvas — Claude Code đọc để lấy đúng số liệu |
